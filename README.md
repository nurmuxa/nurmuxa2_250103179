## 👋 About this repository

This repository contains my practical work for the **Software Architecture & Design Patterns** course.

The goal is to learn not just *how* to implement a pattern, but **when and why** to use it — with readable Java code, examples, and a healthy amount of debugging.

## 🧩 Patterns explored

| Pattern | Superpower |
| :--- | :--- |
| **Strategy** | Swap algorithms without rewriting the client |
| **Adapter** | Make incompatible interfaces collaborate |
| **Decorator** | Add new behavior without modifying the original class |
| **Proxy** | Control access to an object |
| **Bridge** | Separate abstraction from implementation |
| **Facade** | Hide complex subsystems behind one simple interface |

> **Design principle:** Prefer composition over inheritance. Prefer working code over mysterious bugs.
